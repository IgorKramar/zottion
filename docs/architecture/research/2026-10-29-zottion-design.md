# zottion: принятый вариант v0.1

29 октября 2026 года. Автор: Igor Kramar.

Исходное предложение уточнено планом разработки: Rust вместо предложения Go;
прямой официальный REST вместо альтернативы с ntn; Linux и macOS обязательны,
управление Vim через EdTUI, лицензия MIT. Неофициальный API и браузерная
автоматизация содержимого не используются.

Единое приложение содержит app/notion/content/store/tui/cli/auth; отдельные
crates по слоям не создаются. OAuth-сервис вынесен потому, что client_secret
не может находиться в распространяемом клиенте. Страницы идут прямо в Notion.

Первая версия охватывает заметки, основные блоки и rich text, существующие базы
задач, таблицу/доску, поиск названий/загруженного, CLI, черновики и восстановление.
Вложения, комментарии, схемы, другие views и AI — следующие выпуски.

Текущая [архитектура](../../../ARCHITECTURE.md), [матрица операций](../../capabilities.md)
и [проверки](../../verification.md) отражают реализацию. Реальный API/OAuth и
чистая установка на обеих ОС остаются отдельными критериями публикации.

Сохранность важнее пересоздания документа: PATCH по ID, raw JSON, защита
неизвестного, черновик до отправки, ограниченные повторы чтения, отсутствие
автоматических повторов неоднозначной записи. Предварительное сравнение
не устраняет гонку без серверного CAS.
