# Матрица v0.1

Автор: Igor Kramar. Версия API закреплена: `2026-03-11`.
«Реализовано» означает наличие операции и локальных проверок; настоящий
workspace и права конкретной connection проверяются отдельно.

| Область | Реализация | Граница |
|---|---|---|
| Страницы | get/create/title, move в страницу, trash/restore | Реальные права и поведение корзины требуют приёмки |
| Блоки | paragraph, heading 1–3, списки, to-do, toggle, quote, callout, code, divider; append/PATCH | Никакого пересоздания всей страницы |
| Rich text | Просмотр, ограниченная безопасная текстовая правка, форматирование диапазона, явный JSON | Не разделяем mentions; не стираем неизвестные атрибуты |
| Неизвестные блоки | Raw JSON и защищённое отображение; чтение детей при наличии | Редактирование/удаление запрещены |
| Дочерние страницы | Навигация по page ID | Не удаляются при изменении соседнего текста |
| Перенос обычных блоков | Явный отказ с кодом 7 | Нет подтверждённой реализации; копирование/удаление не подменяет перенос |
| Задачи | Схема data source, создание страниц, чтение/изменение существующих свойств | Схема и новые select options не меняются |
| Свойства | title, rich_text, status/select, multi_select, checkbox, date, number, URL, people, relation | Длинные значения дочитываются; formula/rollup только чтение с ограничениями вычисления API |
| Таблица/доска | Ячейки, горизонтальная прокрутка, группировка status/select, смена статуса | Настройки интерфейса локальны текущему запуску |
| Реальные views | list/get/query, TUI table/board | Сохраняются query ID и признак неполного ответа; общий view не редактируется |
| Поиск | Названия API, содержимое загруженного через FTS5 | Не является полным реестром workspace |
| Офлайн | Кэш, черновики, явная отправка после проверки | Нет автоматической очереди |
| OAuth | Одноразовый handoff, refresh/revoke, keychain | Нужны свои public connection и сервер |
| CLI | stdin, версии JSON, курсоры, exit codes, профили, completion | Без скрытого браузерного входа |

Вложения, комментарии, изменение схем, остальные виды, AI, webhooks и плагины
не входят в v0.1. Предварительная проверка не заменяет серверный CAS. Истёкшие
view queries не пересоздаются скрыто во время пагинации; неполный результат — код 8.

## Приёмка настоящего API

В отдельной тестовой странице подготовьте вложенный toggle, каждый основной
тип блока, rich text с ссылкой/оформлением/mention, to-do, дочернюю страницу и
неподдерживаемый элемент, созданный в веб-интерфейсе. Сохраните исходный JSON
через page get --content и block children для вложенности. Не помещайте токен
или реальные личные данные в fixtures.

Проверьте чтение → изменение одного фрагмента → повторное чтение: ID, соседи,
упоминания, ссылки и неизвестный элемент должны сохраниться. Отдельно создайте
страницу, переместите её, отправьте в корзину и восстановите.

В тестовой data source проверьте создание задачи, статус через доску и CLI,
фильтры/сортировки, более одной страницы результатов и relation/people длиннее
25 элементов. Сверьте фактические views, включая серверное усечение результата.

Измените открытый блок в браузере, затем выполните :w: должен появиться конфликт,
черновик остаётся. После принудительного завершения отправляющего клиента
следующая запись требует operation check/ручную сверку, без повторного создания.

Протокол OAuth проверяется по [инструкции](oauth.md). Эти сценарии не запускались
в реальном workspace без предоставленных тестовых доступов.
