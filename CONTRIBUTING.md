# Участие в zottion

Автор: Igor Kramar.

Для ошибки откройте [issue](https://github.com/IgorKramar/zottion/issues): версия,
ОС, терминал/размер окна, шаги воспроизведения и ожидаемый результат. Для идеи
опишите сценарий, который станет проще. Сообщения можно писать на русском или английском.

Соберите checkout с Rust 1.91 и выполните:

```sh
cargo fmt --all --check
cargo clippy --workspace --all-targets --locked -- -D warnings
cargo test --workspace --locked
python3 scripts/check_terminal.py
```

Для PR опишите изменение поведения и проверку. Обновляйте обе версии README,
если меняется пользовательский интерфейс. Проверки настоящего API запускайте
только в выделенном тестовом workspace. Не добавляйте токены, личные заметки,
локальные настройки и пользовательские ответы API в код, fixtures или отчёты.

Сохранность черновиков, неизвестных блоков и rich text — часть контракта.
Изменяющие запросы с неизвестным исходом нельзя повторять автоматически.
См. [архитектуру](ARCHITECTURE.md) и [матрицу возможностей](docs/capabilities.md).
