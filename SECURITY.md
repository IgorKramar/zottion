# Сообщить об уязвимости

Автор: Igor Kramar.

Для уязвимости используйте [приватное сообщение через GitHub Security](https://github.com/IgorKramar/zottion/security/advisories/new).
Не публикуйте токены, authorization codes, содержимое keychain и личные заметки
в issues, PR или логах. Для воспроизведения достаточно синтетического примера.

Укажите версию/коммит, затронутый компонент, шаги и возможные последствия.
Проект находится в ранней разработке; формального SLA и поддерживаемых
стабильных веток пока нет. Последние исправления появляются в main.

## Report a vulnerability

Please use [GitHub private vulnerability reporting](https://github.com/IgorKramar/zottion/security/advisories/new).
Include the version or commit, affected component, reproduction steps and impact.
Use synthetic data and keep credentials and private page contents out of reports.
There is no response-time SLA or supported stable release branch yet.
